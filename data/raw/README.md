# data/raw/

Aquí van los 4 CSV originales del SIAGIE (MINEDU), descargados del Portal de Datos Abiertos del Perú:

- `Matriculación_y_Trayectoria_Estudiantil_2021.csv`
- `Matriculación_y_Trayectoria_Estudiantil_2022.csv`
- `Matriculación_y_Trayectoria_Estudiantil_2023.csv`
- `Matriculación_y_Trayectoria_Estudiantil_2024.csv`

No se versionan en git (ver `.gitignore`) porque cada archivo pesa ~60 MB. Colócalos aquí manualmente antes de ejecutar el notebook (ver README.md principal, sección "Dataset").
